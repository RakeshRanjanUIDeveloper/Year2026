React + Redux — generic flow

A reliable reference for building any React-Redux feature

1
Component UI layer
FeatureComponent.jsx
  • User interacts — click, submit, change
  • useDispatch() → calls action creator first, then dispatch(actionCreator(payload)) sends returned action object to Store
↓
2
Action creator
featureActions.js
  • Returns a plain object { type: ACTION_TYPE, payload: data }
  • Never contains state logic — just describes what happened and carries the payload
↓
3
Constants
featureConstants.js
  • export const ACTION_TYPE = "ACTION_TYPE"
  • Shared between action creator and reducer — avoids typos
↓
4
Store single source of truth
store.js
  • createStore(rootReducer) internally does 2 things (3 if middleware configured):
  • ① Receives the action from dispatch(action)
  • ② Passes through any middleware (thunk, saga, logger) — optional
  • ③ Forwards that action to rootReducer(state, action)
↓
5
Root reducer registers reducers
rootReducer.js
  • combineReducers({ todo: todoReducer }) — you pass reducers, not actions
  • Action is automatically broadcasted to every registered reducer by Redux internally
  • Each reducer checks action.type — handles it or returns default state
↓
6
Reducer decides new state
featureReducer.js
  • switch(action.type) matches the constant
  • Returns a new state object — never mutates directly
  • default returns current state unchanged
↓
7
Store saves new state
  • New state committed to the store internally by createStore
  • <Provider store={store}> in App.jsx watches the store and notifies all components using useSelector
↓
8
Component re-renders
  • useSelector(state => state.feature.data) reads updated state from Store
  • React re-renders only the affected component

Key concepts

useDispatch — calls action creator first, then sends returned action object to Store
useSelector — component reads state from Store
Reducer never talks to component directly — Store is always in between
One constant → one action creator → one case in reducer
Never mutate state — always spread { ...state, field: value }
combineReducers key = namespace in useSelector → state.todo, state.user
Action creator describes what happened — Reducer decides what changes
<Provider> — does not update state, just makes store accessible to all components
