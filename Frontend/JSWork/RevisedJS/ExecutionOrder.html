• In Node.js => Sync → nextTick queue → microtask queue → macrotask
  • In the browser => Sync → microtask queue → macrotask
  • queueMicrotask is a browser/Node.js built-in function that lets you manually push a callback into the microtask queue.

MicroTasks:

  • Promise.then() / .catch() / .finally()
  • await (everything after await resumes as a microtask)
  • queueMicrotask(() => ...)
  • MutationObserver callbacks (browser-specific)
  • process.nextTick (Node.js only) — actually runs before other microtasks, it has its own queue that drains first

Macrotasks:

  • setTimeout
  • setInterval
  • setImmediate (Node.js only)
  • I/O callbacks (file read, network — Node.js)
  • UI rendering / paint (browser)
  • MessageChannel

Execution Order

  • sync1. Sync — console.log("start")
  • sync2. Sync — Promise executor runs immediately
  • sync3. Sync — inside async fn, before await
  • sync4. Sync — console.log("end")
  • micro5. Microtask — Promise.then()
  • micro6. Microtask — queueMicrotask()
  • micro8. Microtask — after await (resumes as microtask)
  • micro7. Microtask — nested Promise.then() (queued inside step 5)
  • macro9. Macrotask — setTimeout(..., 0)
