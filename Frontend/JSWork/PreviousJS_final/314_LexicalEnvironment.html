Lexical Environment

JavaScript Interview Topic — Easy · Medium · Hard Challenges

📖 Concept

A Lexical Environment is the internal structure JS creates every time a function or block is executed. It holds two things:

  • Environment Record — stores all variables and functions declared in that scope
  • Outer reference — a pointer to the parent lexical environment (enables scope chain)

When JS looks up a variable, it searches the current environment first, then follows the outer reference chain upward — this is the scope chain.

function outer() {
  let x = 10; // stored in outer's Lexical Environment
  function inner() {
    console.log(x); // found via outer reference → 10
  }
  inner();
}

🎯 Interview Challenges

EASY Predict the Output

What will this log and why? Explain using lexical environment.

// Starter Code
function a() {
  let msg = 'hello';
  function b() {
    console.log(msg); // ?
  }
  b();
}
a();
▶ Show Solution 
// Output: 'hello'
// b() does not have 'msg' in its own environment record,
// so JS follows the outer reference to a()'s lexical environment
// and finds msg = 'hello' there. This is the scope chain in action.
MEDIUM Closure via Lexical Environment

Create a makeMultiplier(x) that returns a function. The returned function takes y and returns x * y. Each call to makeMultiplier must have its own independent x.

// Starter Code
function makeMultiplier(x) {
  // return a function here
}

const double = makeMultiplier(2);
const triple = makeMultiplier(3);
console.log(double(5));  // 10
console.log(triple(5));  // 15
▶ Show Solution 
function makeMultiplier(x) {
  return function(y) {
    return x * y; // x is captured from makeMultiplier's lexical env
  };
}

const double = makeMultiplier(2);
const triple = makeMultiplier(3);
console.log(double(5));  // 10
console.log(triple(5));  // 15
// Each call creates a NEW lexical environment with its own x.
HARD Variable Shadowing + Scope Chain

Predict all console.log outputs and explain which lexical environment each variable lookup resolves in.

// Starter Code
let x = 'global';

function outer() {
  let x = 'outer';
  function middle() {
    function inner() {
      console.log(x); // ?
    }
    inner();
  }
  let y = 'outer-y';
  function sibling() {
    console.log(y); // ?
    console.log(x); // ?
  }
  middle();
  sibling();
}
outer();
console.log(x); // ?
▶ Show Solution 
// Output:
// 'outer'  — inner has no x, middle has no x, outer has x='outer'
// 'outer-y' — sibling finds y in outer's env
// 'outer'  — sibling finds x in outer's env
// 'global' — outer() call is done; global x unchanged

// Key: each function captures the env where it was DEFINED, not where called.
