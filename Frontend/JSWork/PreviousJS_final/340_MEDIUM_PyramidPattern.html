Pyramid Pattern

MEDIUM tcs

📋 Problem

Build a centered pyramid of * characters of height n using loops.

pyramid(4):
   *
  ***
 *****
*******

💡 Approach

For each row i (1 to n): spaces = n-i, stars = 2*i-1. Print spaces + stars.

✅ Solution

function pyramid(n) {
  for (let i = 1; i <= n; i++) {
    const spaces = ' '.repeat(n - i);
    const stars  = '*'.repeat(2 * i - 1);
    console.log(spaces + stars);
  }
}

pyramid(4);
// Output:
//    *
//   ***
//  *****
// *******

pyramid(5);

⏱ Complexity

Time: O(n²)Space: O(n)
