Shortest Distance from Source — BFS

📋 Problem

Find the shortest distance from a source node to all other nodes in an unweighted undirected graph using BFS.

// Graph: 0-1, 0-2, 1-3, 2-3, 3-4
shortestDistances(5, [[0,1],[0,2],[1,3],[2,3],[3,4]], 0)
// [0, 1, 1, 2, 3]

💡 Approach

BFS naturally finds shortest paths in unweighted graphs. Use a distance array initialised to -1. Start BFS from source with distance 0. Update each unvisited neighbour as dist[node]+1.

✅ Solution

function shortestDistances(numNodes, edges, source) {
  const adj = Array.from({ length: numNodes }, () => []);
  for (const [u, v] of edges) {
    adj[u].push(v);
    adj[v].push(u); // undirected
  }

  const dist = new Array(numNodes).fill(-1);
  dist[source] = 0;
  const queue = [source];

  while (queue.length) {
    const node = queue.shift();
    for (const neighbor of adj[node]) {
      if (dist[neighbor] === -1) {
        dist[neighbor] = dist[node] + 1;
        queue.push(neighbor);
      }
    }
  }

  return dist; // -1 means unreachable
}

console.log(shortestDistances(5, [[0,1],[0,2],[1,3],[2,3],[3,4]], 0));
// [0, 1, 1, 2, 3]

console.log(shortestDistances(6, [[0,1],[0,2],[1,3],[2,4],[3,5]], 0));
// [0, 1, 1, 2, 2, 3]
