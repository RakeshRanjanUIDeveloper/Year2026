undefined — variable exists but has no value:

  • declared with var but not assigned
  • declared with let but not assigned
  • accessing var before declaration (hoisting)
  • object property that doesn't exist
  • function that returns nothing

ReferenceError: not defined — variable doesn't exist at all:

  • never declared anywhere
  • accessing let / const before declaration (TDZ)
  • declared inside a block/function and accessed outside
