Worker Pool

HARD stripedropboxmeesho

📋 Problem

Implement a Worker Pool that manages multiple concurrent workers. A pool of N workers should pick up tasks from a queue and process them concurrently.

const pool = new WorkerPool(3); // 3 concurrent workers
pool.run(task1);
pool.run(task2); // runs concurrently if worker available
pool.run(task3);
pool.run(task4); // queued until a worker frees up

💡 Approach

Maintain a count of active workers and a queue of pending tasks. When a task completes, check the queue and start the next pending task if workers are available.

✅ Solution

class WorkerPool {
  constructor(concurrency) {
    this.concurrency = concurrency;
    this.active = 0;
    this.queue = [];
  }

  run(task) {
    return new Promise((resolve, reject) => {
      const wrapped = () =>
        Promise.resolve()
          .then(task)
          .then(resolve, reject)
          .finally(() => {
            this.active--;
            this._next();
          });

      if (this.active < this.concurrency) {
        this.active++;
        wrapped();
      } else {
        this.queue.push(wrapped); // wait in queue
      }
    });
  }

  _next() {
    if (this.queue.length && this.active < this.concurrency) {
      this.active++;
      this.queue.shift()(); // dequeue and run
    }
  }
}

// Demo
function makeTask(id, ms) {
  return () => new Promise(resolve => {
    console.log(`Task ${id} started (active workers processing)`);
    setTimeout(() => { console.log(`Task ${id} done`); resolve(id); }, ms);
  });
}

const pool = new WorkerPool(2); // only 2 concurrent
Promise.all([
  pool.run(makeTask(1, 400)),
  pool.run(makeTask(2, 200)),
  pool.run(makeTask(3, 300)), // queued initially
  pool.run(makeTask(4, 100)), // queued initially
]).then(results => console.log('All done:', results));
