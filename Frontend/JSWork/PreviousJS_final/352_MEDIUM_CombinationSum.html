Combination Sum

MEDIUM amazonmeeshoairbnb

📋 Problem

Find all unique combinations of candidates that sum to target. Each number may be used unlimited times. Return all combinations.

combinationSum([2,3,6,7], 7)
// [[2,2,3],[7]]

combinationSum([2,3,5], 8)
// [[2,2,2,2],[2,3,3],[3,5]]

💡 Approach

Backtracking: sort candidates, then recursively try each candidate. Allow reuse by not advancing index. Prune when sum exceeds target.

✅ Solution

function combinationSum(candidates, target) {
  const result = [];
  candidates.sort((a, b) => a - b);

  function backtrack(start, current, remaining) {
    if (remaining === 0) {
      result.push([...current]);
      return;
    }
    for (let i = start; i < candidates.length; i++) {
      if (candidates[i] > remaining) break; // pruning
      current.push(candidates[i]);
      backtrack(i, current, remaining - candidates[i]); // reuse same i
      current.pop();
    }
  }

  backtrack(0, [], target);
  return result;
}

console.log(combinationSum([2,3,6,7], 7));
// [[2,2,3],[7]]

console.log(combinationSum([2,3,5], 8));
// [[2,2,2,2],[2,3,3],[3,5]]

⏱ Complexity

Time: O(n^(t/m))Space: O(t/m) depth
