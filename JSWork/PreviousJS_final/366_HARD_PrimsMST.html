📋 Problem

Find the Minimum Spanning Tree of a weighted undirected graph using Prim's algorithm.

// Graph edges: [u, v, weight]
primsMST(5, [[0,1,2],[0,3,6],[1,2,3],[1,3,8],[1,4,5],[2,4,7],[3,4,9]])
// MST weight = 16, edges: (0,1),(1,2),(1,4),(0,3)

💡 Approach

Start from node 0. Maintain a visited set and a min-heap of available edges. Always pick the cheapest edge that connects to an unvisited node.

✅ Solution

function primsMST(numNodes, edges) {
  // Build adjacency list
  const adj = Array.from({ length: numNodes }, () => []);
  for (const [u, v, w] of edges) {
    adj[u].push([v, w]);
    adj[v].push([u, w]);
  }

  // Simple priority queue (min-heap simulation with array sort)
  const visited = new Set();
  const mstEdges = [];
  let totalWeight = 0;

  // [weight, to, from]
  let available = [[0, 0, -1]];

  while (available.length && visited.size < numNodes) {
    available.sort((a, b) => a[0] - b[0]); // sort by weight
    const [w, node, from] = available.shift();

    if (visited.has(node)) continue;
    visited.add(node);
    totalWeight += w;
    if (from !== -1) mstEdges.push([from, node, w]);

    for (const [neighbor, weight] of adj[node]) {
      if (!visited.has(neighbor)) {
        available.push([weight, neighbor, node]);
      }
    }
  }

  if (visited.size !== numNodes) return 'Graph is not connected';

  return { totalWeight, mstEdges };
}

const result = primsMST(5, [[0,1,2],[0,3,6],[1,2,3],[1,3,8],[1,4,5],[2,4,7],[3,4,9]]);
console.log('Total MST weight:', result.totalWeight); // 16
console.log('MST Edges:', result.mstEdges);

Time: O(E log V) with heapSpace: O(V+E)
