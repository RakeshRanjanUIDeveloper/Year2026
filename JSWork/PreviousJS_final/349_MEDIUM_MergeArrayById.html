Merge Array of Objects by ID

MEDIUM redditslackola

📋 Problem

Given two arrays of objects with an 'id' field, merge them so that objects with the same id are combined (second array values override first).

merge(
  [{id:1,a:1},{id:2,a:2}],
  [{id:1,b:10},{id:3,b:30}]
)
// [{id:1,a:1,b:10},{id:2,a:2},{id:3,b:30}]

💡 Approach

Build a Map keyed by id from the first array. Iterate second array and merge each object into the map entry. Convert map values back to array.

✅ Solution

function mergeById(arr1, arr2) {
  const map = new Map();

  for (const item of arr1) {
    map.set(item.id, { ...item });
  }
  for (const item of arr2) {
    if (map.has(item.id)) {
      map.set(item.id, { ...map.get(item.id), ...item });
    } else {
      map.set(item.id, { ...item });
    }
  }

  return Array.from(map.values());
}

const a1 = [{ id:1, name:'Alice', age:25 }, { id:2, name:'Bob' }];
const a2 = [{ id:1, age:26, city:'Delhi' }, { id:3, name:'Carol' }];

console.log(mergeById(a1, a2));
// [{id:1,name:'Alice',age:26,city:'Delhi'}, {id:2,name:'Bob'}, {id:3,name:'Carol'}]

// Verify order: preserves insertion order
const r = mergeById([{id:2,v:'b'},{id:1,v:'a'}],[{id:1,v:'A'}]);
console.log(r); // [{id:2,v:'b'},{id:1,v:'A'}]

⏱ Complexity

Time: O(n+m)Space: O(n+m)
