Power of Four

EASY googlemetamicrosoftamazon

📋 Problem

Determine if a given integer n is a power of four. A number is a power of four if n = 4^k for some integer k >= 0.

isPowerOfFour(16)  // true  (4^2)
isPowerOfFour(5)   // false
isPowerOfFour(1)   // true  (4^0)
isPowerOfFour(64)  // true  (4^3)

💡 Approach

Three approaches: (1) Loop: divide by 4 until 1 or odd. (2) Math: log base 4 must be integer. (3) Bit manipulation: must be power of 2 AND the set bit must be at an even position (0,2,4...).

✅ Solution

// Method 1: Loop
function isPowerOfFourLoop(n) {
  if (n <= 0) return false;
  while (n > 1) {
    if (n % 4 !== 0) return false;
    n = n / 4;
  }
  return true;
}

// Method 2: Math
function isPowerOfFourMath(n) {
  if (n <= 0) return false;
  const log = Math.log(n) / Math.log(4);
  return Number.isInteger(Math.round(log * 1e10) / 1e10);
}

// Method 3: Bit manipulation (fastest)
// Power of 4: exactly one bit set, at position 0,2,4,6...
// 0x55555555 = 01010101...01 in binary (marks even bit positions)
function isPowerOfFour(n) {
  return n > 0 && (n & (n - 1)) === 0 && (n & 0x55555555) !== 0;
}

console.log(isPowerOfFour(1));   // true
console.log(isPowerOfFour(16));  // true
console.log(isPowerOfFour(64));  // true
console.log(isPowerOfFour(5));   // false
console.log(isPowerOfFour(8));   // false (power of 2, not 4)

⏱ Complexity

Time: O(log n)Space: O(1)
