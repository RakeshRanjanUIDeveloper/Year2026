Compress String

MEDIUM amazonmicrosoft

📋 Problem

Compress a string by replacing consecutive repeated characters with the character followed by its count. If compressed string is not shorter, return original.

compress("aabcccdddd")  // "a2bc3d4"
compress("abc")          // "abc" (not shorter, return original)
compress("aabbcc")       // "a2b2c2"

💡 Approach

Walk through the string tracking current character and count. When character changes, append char+count (skip count if 1). Compare lengths at end.

✅ Solution

function compress(str) {
  if (!str.length) return str;
  let result = '';
  let count = 1;

  for (let i = 1; i <= str.length; i++) {
    if (str[i] === str[i - 1]) {
      count++;
    } else {
      result += str[i - 1] + (count > 1 ? count : '');
      count = 1;
    }
  }

  return result.length < str.length ? result : str;
}

console.log(compress("aabcccdddd")); // "a2bc3d4"
console.log(compress("abc"));        // "abc"
console.log(compress("aabbcc"));     // "a2b2c2"
console.log(compress("aaaa"));       // "a4"
console.log(compress(""));           // ""
console.log(compress("aAbBcc"));     // "aAbBc2" (case-sensitive)

Time: O(n)Space: O(n)
