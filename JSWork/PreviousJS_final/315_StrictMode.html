Strict Mode — use strict

JavaScript Interview Topic — Easy · Medium · Hard Challenges

📖 Concept

"use strict" activates strict mode — a restricted variant of JS that catches common mistakes and prevents unsafe features.

  • Eliminates silent errors (throws them instead)
  • Prevents using undeclared variables
  • this is undefined in regular functions (not global)
  • Disallows duplicate parameter names
  • Makes eval and arguments safer
  • Can be applied to a whole file or individual functions
"use strict";
x = 5; // ReferenceError: x is not defined
function f() { return this; } // undefined, not window

🎯 Interview Challenges

EASY Spot the Strict Mode Error

Which of these lines will throw in strict mode? Identify each one.

// Starter Code
"use strict";

// Line A
undeclared = 10;

// Line B
let obj = {};
Object.defineProperty(obj, 'x', { value: 42, writable: false });
obj.x = 100;

// Line C
function sum(a, a) { return a + a; }

// Which lines throw?
▶ Show Solution 
// Line A → ReferenceError: undeclared is not defined
//   (without strict mode, it silently creates a global)

// Line B → TypeError: Cannot assign to read only property 'x'
//   (without strict mode, the assignment silently fails)

// Line C → SyntaxError: Duplicate parameter name not allowed in strict mode
//   (without strict mode, second 'a' just shadows the first)
MEDIUM this in Strict Mode

Write two versions of a function — one strict, one not — and show how 'this' differs when called as a plain function (not as a method).

// Starter Code
function nonStrict() {
  console.log(this); // ?
}

function strict() {
  "use strict";
  console.log(this); // ?
}

nonStrict();
strict();
▶ Show Solution 
function nonStrict() {
  console.log(this); // Window (in browser) or global object in Node
}

function strict() {
  "use strict";
  console.log(this); // undefined — strict mode does NOT default 'this' to global
}

nonStrict(); // [object Window]
strict();    // undefined

// This matters for constructors and class methods — strict mode prevents
// accidentally polluting the global object through this.
HARD Build a Strict-Mode Safe Module Pattern

Create a BankAccount module using an IIFE with strict mode. It should have deposit(n), withdraw(n), and getBalance(). Withdrawing more than the balance should throw an error.

// Starter Code
const BankAccount = (function() {
  "use strict";
  // private state
  // implement: deposit, withdraw, getBalance
})();

BankAccount.deposit(100);
BankAccount.deposit(50);
BankAccount.withdraw(30);
console.log(BankAccount.getBalance()); // 120
BankAccount.withdraw(200); // should throw
▶ Show Solution 
const BankAccount = (function() {
  "use strict";
  let balance = 0;

  return {
    deposit(n) {
      if (typeof n !== 'number' || n <= 0) throw new Error('Invalid amount');
      balance += n;
    },
    withdraw(n) {
      if (typeof n !== 'number' || n <= 0) throw new Error('Invalid amount');
      if (n > balance) throw new Error(`Insufficient funds. Balance: ${balance}`);
      balance -= n;
    },
    getBalance() { return balance; }
  };
})();

BankAccount.deposit(100);
BankAccount.deposit(50);
BankAccount.withdraw(30);
console.log(BankAccount.getBalance()); // 120
try { BankAccount.withdraw(200); } catch(e) { console.log(e.message); }
