Callback Hell

JavaScript Interview Topic — Easy · Medium · Hard Challenges

📖 Concept

Callback Hell (also called the "Pyramid of Doom") occurs when callbacks are nested inside callbacks multiple levels deep, making code hard to read, debug, and maintain.

getData(function(a) {
  getMoreData(a, function(b) {
    getEvenMore(b, function(c) {
      // deeply nested — callback hell
    });
  });
});

Solutions: Named functions → Promises → async/await

🎯 Interview Challenges

EASY Identify the Problem

Rewrite this callback hell using named functions to flatten the nesting (same behaviour, readable structure).

// Starter Code
function getUser(id, cb) { setTimeout(() => cb({ id, name: 'Alice' }), 100); }
function getOrders(user, cb) { setTimeout(() => cb([1, 2, 3]), 100); }
function getOrderDetail(id, cb) { setTimeout(() => cb({ id, total: 99 }), 100); }

// Callback hell version:
getUser(1, function(user) {
  getOrders(user, function(orders) {
    getOrderDetail(orders[0], function(detail) {
      console.log(detail);
    });
  });
});
▶ Show Solution 
function getUser(id, cb) { setTimeout(() => cb({ id, name: 'Alice' }), 100); }
function getOrders(user, cb) { setTimeout(() => cb([1, 2, 3]), 100); }
function getOrderDetail(id, cb) { setTimeout(() => cb({ id, total: 99 }), 100); }

// Named function approach — flat, readable:
function handleDetail(detail) { console.log(detail); }
function handleOrders(orders) { getOrderDetail(orders[0], handleDetail); }
function handleUser(user) { getOrders(user, handleOrders); }

getUser(1, handleUser);
MEDIUM Convert to Promises

Wrap the three callback functions above in Promises and chain them cleanly.

// Starter Code
function getUser(id) {
  return new Promise(resolve => setTimeout(() => resolve({ id, name: 'Alice' }), 100));
}
function getOrders(user) {
  // wrap in Promise
}
function getOrderDetail(id) {
  // wrap in Promise
}

// Chain them:
getUser(1)
  .then(/* ... */)
  .then(/* ... */)
  .then(detail => console.log(detail));
▶ Show Solution 
function getUser(id) {
  return new Promise(resolve => setTimeout(() => resolve({ id, name: 'Alice' }), 100));
}
function getOrders(user) {
  return new Promise(resolve => setTimeout(() => resolve([1, 2, 3]), 100));
}
function getOrderDetail(id) {
  return new Promise(resolve => setTimeout(() => resolve({ id, total: 99 }), 100));
}

getUser(1)
  .then(user => getOrders(user))
  .then(orders => getOrderDetail(orders[0]))
  .then(detail => console.log(detail)); // { id: 1, total: 99 }
HARD Convert to async/await with Error Handling

Convert the Promise chain above to async/await. Add error handling so if any step fails, log the error and continue gracefully.

// Use same Promise-based functions from medium challenge

  // implement with try/catch
}

loadOrderDetail(1);
▶ Show Solution 
function getUser(id) {
  return new Promise(resolve => setTimeout(() => resolve({ id, name: 'Alice' }), 100));
}
function getOrders(user) {
  return new Promise(resolve => setTimeout(() => resolve([1, 2, 3]), 100));
}
function getOrderDetail(id) {
  return new Promise(resolve => setTimeout(() => resolve({ id, total: 99 }), 100));
}

async function loadOrderDetail(userId) {
  try {
    const user = await getUser(userId);
    const orders = await getOrders(user);
    const detail = await getOrderDetail(orders[0]);
    console.log('Detail:', detail);
    return detail;
  } catch (err) {
    console.error('Failed to load order:', err.message);
    return null;
  }
}

loadOrderDetail(1);
