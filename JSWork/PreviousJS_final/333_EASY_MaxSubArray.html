Max SubArray

EASY amazonflipkartgoogle

📋 Problem

Given an integer array nums, find the contiguous subarray which has the largest sum and return its sum.

Input:  [-2,1,-3,4,-1,2,1,-5,4]
Output: 6  (subarray [4,-1,2,1])

Input:  [1]
Output: 1

Input:  [-1,-2,-3]
Output: -1

💡 Approach

Use Kadane's Algorithm: track currentSum and maxSum. At each element, decide whether to extend the existing subarray or start a new one from current element.

✅ Solution

// Kadane's Algorithm — O(n)
function maxSubArray(nums) {
  let maxSum = nums[0];
  let currentSum = nums[0];

  for (let i = 1; i < nums.length; i++) {
    currentSum = Math.max(nums[i], currentSum + nums[i]);
    maxSum = Math.max(maxSum, currentSum);
  }
  return maxSum;
}

console.log(maxSubArray([-2,1,-3,4,-1,2,1,-5,4])); // 6
console.log(maxSubArray([1]));                       // 1
console.log(maxSubArray([-1,-2,-3]));               // -1
console.log(maxSubArray([5,4,-1,7,8]));             // 23
