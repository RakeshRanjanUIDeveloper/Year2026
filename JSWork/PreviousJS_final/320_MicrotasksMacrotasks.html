Microtasks vs Macrotasks

JavaScript Interview Topic — Easy · Medium · Hard Challenges

📖 Concept

The JS event loop processes tasks in two queues:

  • Macrotask queue (Task Queue): setTimeout, setInterval, I/O, UI events
  • Microtask queue: Promise callbacks (.then/.catch/.finally), queueMicrotask(), MutationObserver

Order of execution: Synchronous code → ALL microtasks → ONE macrotask → ALL microtasks → ONE macrotask → ...

console.log('1');
setTimeout(() => console.log('2'), 0);   // macrotask
Promise.resolve().then(() => console.log('3')); // microtask
console.log('4');
// Output: 1, 4, 3, 2

HARD Implement a task scheduler respecting micro/macro priority

Build a scheduler that accepts tasks with priority 'micro' or 'macro'. Run micro tasks before macro tasks, regardless of insertion order.

// Starter Code

  // implement add(fn, priority) and run()
}

const s = createScheduler();
s.add(() => console.log('macro 1'), 'macro');
s.add(() => console.log('micro 1'), 'micro');
s.add(() => console.log('macro 2'), 'macro');
s.add(() => console.log('micro 2'), 'micro');
s.run();
// micro 1 → micro 2 → macro 1 → macro 2
▶ Show Solution 
function createScheduler() {
  const micro = [], macro = [];
  return {
    add(fn, priority) {
      priority === 'micro' ? micro.push(fn) : macro.push(fn);
    },
    run() {
      [...micro, ...macro].forEach(fn => fn());
    }
  };
}

const s = createScheduler();
s.add(() => console.log('macro 1'), 'macro');
s.add(() => console.log('micro 1'), 'micro');
s.add(() => console.log('macro 2'), 'macro');
s.add(() => console.log('micro 2'), 'micro');
s.run(); // micro 1 → micro 2 → macro 1 → macro 2
